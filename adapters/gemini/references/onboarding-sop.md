# Onboarding / SOP Reference

Use this reference when the user needs setup instructions or a standard operating procedure.

## Purpose

Onboarding and SOP documents should make it easy to start correctly and repeat the right process later.

## Recommended Structure

1. Purpose
2. Prerequisites
3. Access / Inputs Needed
4. Setup Steps
5. Normal Workflow
6. Edge Cases / Troubleshooting
7. Verification
8. Handoff / Ownership
9. Maintenance Notes

## Writing Rules

- Keep the steps deterministic.
- Write for the person who has never done the task before.
- Use explicit inputs, outputs, and checks.
- Separate setup from operational routine.

## Good SOP Triggers

- team onboarding
- project handoff
- recurring internal process
- environment setup
- operational playbook

## Quality Check

- A new person should be able to follow it without asking what to do next.
- The document should make the “done” state obvious.
